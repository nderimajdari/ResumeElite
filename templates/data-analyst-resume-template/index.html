The question in every analyst interview

"What decision changed because of your work?" Write your resume so it already answers it. For each project or role: the question, the method, the decision, the value.

Churn prediction dashboard — SQL, Python, Tableau. Flagged at-risk accounts two months earlier; customer success saved an estimated $400K ARR in the first quarter.

Tools and methods

The rail is titled Tools & Methods. Order by how often you use them:

SQL (Postgres, BigQuery)      daily
Python (pandas, scikit-learn) weekly
Tableau / Power BI / Looker   dashboards
Statistics                    A/B testing, regression

Skill bars are a visual cue, not a test score — keep them honest and relative.

Career changers

If you are moving into data, two or three solid portfolio projects using real public datasets beat any certificate. Link the notebook or dashboard.

What to leave out

Lists of every Python library, MOOCs completed in a weekend, and screenshots of charts. A recruiter has seconds; spend them on outcomes.
