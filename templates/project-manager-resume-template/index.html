The Project Manager resume template

A layout that thinks like a plan. A three-phase bar runs under your name, dates appear as small Gantt-style tags above each role, and the side card puts Core Competencies and certifications where they are seen first.

Scope first, then delivery

Each role under Project Leadership should open with the shape of the work: budget, team size, number of concurrent projects, methodology.

Run four concurrent infrastructure projects up to $8M with teams of up to 25, hybrid Agile and stage-gate.

Then show delivery: on time, on budget, risks caught early, a stakeholder win.

Certifications that filter

PMP, PRINCE2, CAPM, PMI-ACP, CSM or PSM. Put them in the side card with issuer and year. Many postings filter on PMP specifically, so spell it out as well as abbreviating it once.

Tools

Jira, MS Project, Smartsheet, Asana, Confluence, Power BI. Name the ones you planned and reported in, not every tool you have logged into.

Avoid the duty list

"Responsible for managing timelines and stakeholders" describes every project manager. "Recovered a CRM rollout running 6 weeks late and delivered on the original date" describes you.
